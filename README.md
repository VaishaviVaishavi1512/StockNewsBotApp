This project introduces an AI-powered stock trading framework that combines financial news sentiment, technical indicators, and contextual reasoning to generate real-time trading signals. The system collects news from platforms like Moneycontrol and Economic Times, uses NER to filter stock-specific updates, and applies FinBERT to determine sentiment polarity. These insights are cross-checked with indicators such as SMA, EMA, RSI, and MACD to produce reliable buy/sell decisions. A RAG module enhances decision-making by referencing historical market scenarios, while a dynamic risk-management layer adjusts stop-loss levels based on volatility. The system also features crash detection, trade logging, backtesting, and integrates with broker APIs (Zerodha/Alpaca) through FastAPI and Streamlit for real-time monitoring.
